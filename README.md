# Meera E-Commerce Sales Dashboard

## Project Overview
This Power BI dashboard analyzes e-commerce sales performance using interactive visualizations and filters.

## Features
- Sales Analysis
- Profit Analysis
- Category-wise Performance
- Monthly Profit Trends
- State-wise Filtering

## Tools Used
- Power BI
- Data Analytics
- Data Visualization
